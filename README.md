# signals-core
Библиотека обработки сигналов

## Назначение
Библиотека предметной логики для работы с одноканальными сигналами: хранение сигнала, запись и чтение csv-файлов, офлайн и онлайн фильтрация скользящим средним, детектирование выходов сигнала за границы допустимого диапазона.

Библиотека не зависит от пользовательского интерфейса и собирается самостоятельно, без приложения.

## Состав репозитория
- `SignalProcessing.Core.sln` – решение библиотеки
- `SignalProcessing.Core` – проект библиотеки классов (Class Library)

## Состав библиотеки
| Класс | Назначение | Исключения |
|---|---|---|
| `SingleChannelSignal` | Одноканальный сигнал: массив значений `Data` и частота квантования `Frequency` в герцах. Свойство `TimeTick` возвращает моменты времени отсчетов в секундах. | `ArgumentNullException` – массив значений равен `null`.<br>`ArgumentOutOfRangeException` – частота равна нулю или отрицательна. |
| `SingleChannelSignalWriter` | Запись сигнала в текстовый csv-файл: в первой строке частота в герцах, в каждой следующей одно значение. Дробная часть всегда отделяется точкой. | Собственных проверок нет. Если файл нельзя создать или записать (нет каталога, нет прав, файл занят), выбрасываются стандартные исключения работы с файлами: `IOException`, `UnauthorizedAccessException`, `DirectoryNotFoundException`. |
| `SingleChannelSignalReader` | Чтение сигнала из csv-файла того же формата, что создает `SingleChannelSignalWriter`. | `InvalidDataException` – файл пуст, какая-либо строка не является числом или частота не положительна; в сообщении указан номер ошибочной строки.<br>`FileNotFoundException` – файл не найден. |
| `OfflineFilter` | Сглаживание всего сигнала сразу скользящим средним с окном, центрированным на отсчете. За краями сигнала повторяются первое и последнее значения. Исходный массив не изменяется. | `ArgumentNullException` – массив значений равен `null`.<br>`ArgumentOutOfRangeException` – размер окна не положителен или четен. |
| `OnlineFilter` | Сглаживание сигнала скользящим средним по мере поступления отсчетов: сигнал можно подавать частями, результат не зависит от разбиения. Учитываются только текущий и предыдущие отсчеты, поэтому результат запаздывает относительно офлайн-фильтра. Метод `Reset` начинает обработку нового сигнала. | `ArgumentOutOfRangeException` – размер окна, переданный в конструктор, не положителен.<br>`ArgumentNullException` – в `Filter` передан `null`. |
| `SingleChannelRangeAnalyzer` | Поиск участков, где сигнал выходит за допустимый диапазон [min, max] не меньше заданного числа отсчетов подряд. О каждом найденном участке сообщает событием `OutOfRange` с номерами первого и последнего отсчета участка (`OutOfRangeEventArgs`). | Явно не выбрасывает. Аргументы не проверяются. |

## Требования
- .NET Framework 4.8
- Visual Studio 2022 или новее

## Связанные репозитории
Библиотека используется приложением из репозитория
https://github.com/blzxc/signals-generator-app

Оба репозитория клонируются в один родительский каталог, рядом друг с другом, под своими именами:

```
C:\talanov\
├── signals-core\
└── signals-generator-app\
```

Решение SignalGenerator.sln из репозитория signals-generator-app ссылается на проект библиотеки
по относительному пути ..\signals-core\SignalProcessing.Core\,
поэтому имена каталогов и их расположение изменять нельзя: иначе решение приложения не откроется.

Сама библиотека собирается самостоятельно, без приложения: достаточно открыть SignalProcessing.Core.sln.
